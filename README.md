# 💰 Smart Expense Tracker (Java)

## 📌 Project Overview

The **Smart Expense Tracker** is a console-based Java application designed to help users manage their daily expenses efficiently. It allows users to record, view, and analyze their spending habits, making financial tracking simple and organized.

---

## 🎯 Problem Statement

Many students and individuals struggle to keep track of their daily expenses, which leads to poor budgeting and financial mismanagement. This project provides a simple solution to record and monitor expenses systematically.

---

## 💡 Features

* ➕ Add new expenses (title, amount, category)
* 📋 View all recorded expenses
* 📊 Calculate total spending
* 💾 Save expenses to a file
* 📂 Load previous data automatically

---

## 🛠️ Technologies Used

* Java (Core Java)
* OOP Concepts (Classes, Objects, Encapsulation)
* Collections (ArrayList)
* File Handling (BufferedReader, BufferedWriter)

## ▶️ How to Run the Project

### 1️⃣ Compile the program

```bash
javac Main.java ExpenseManager.java Expense.java
```

### 2️⃣ Run the program

```bash
java Main
```

---

## 📖 How to Use

1. Run the application
2. Choose from the menu options:

   * Add Expense
   * View Expenses
   * Total Expense
   * Save & Exit
3. Enter details as prompted
4. Data will be saved automatically when you exit
